================================================================================
TROUBLESHOOTING
================================================================================

CAN'T START SERVER?
→ Make sure Node.js is installed
→ Check: node --version
→ Try: npm start in web folder

CAN'T CONNECT TO GAME?
→ Make sure server is running
→ Try: http://localhost:3000
→ Check browser console (F12)

SECOND PLAYER CAN'T JOIN?
→ Copy FULL link with ?room=ID
→ Don't just type room ID
→ Make sure server running on both

KEYBINDS NOT WORKING?
→ Make sure game has started
→ Try different key
→ Reset to defaults
→ Some OS keys are blocked

DEPLOYMENT ISSUES?
→ Read web/README.md deployment section
→ Follow platform-specific steps
→ Check platform documentation

See INSTALLATION_GUIDE.md for detailed troubleshooting
