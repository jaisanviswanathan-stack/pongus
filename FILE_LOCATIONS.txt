================================================================================
                          COMPILATION & EXECUTION
================================================================================

TO COMPILE:
  $ cd pong_with_learning_ai
  $ javac src/game/PingPongGame.java
  
  This automatically compiles all dependencies!

TO RUN:
  $ java -cp src game.PingPongGame

  OR

  $ java -jar build/PongGame.jar
