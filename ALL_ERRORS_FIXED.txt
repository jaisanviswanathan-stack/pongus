TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════

If "javac not found":
  → Install Java JDK from oracle.com
  → Add to PATH environment variable

If compilation fails:
  → Make sure all *.java files are in the project root
  → Try: del *.class (delete old compiled files)
  → Then: javac *.java (recompile)

If game won't start:
  → Verify Java is installed: java -version
  → Check all files are present
  → Try running from Command Prompt (not IDE)
