# Custom Keybinds - Quick Start Guide

## For Player 1 (Host)

1. **Click "Host Game"**
   - Room created
   - See your keybind configuration

2. **Configure Your Keys (Optional)**
   - Default: **W** to move up, **S** to move down
   - To change: Click on a keybind field
   - Field turns yellow and says "press a key"
   - Press any key on your keyboard
   - Key is instantly saved
   - Click "Reset" to go back to defaults

3. **Share Link with Player 2**
   - Copy the generated link
   - Send to your friend

4. **Wait for Player 2**
   - They will see their own keybind config screen
   - Once they join, your "Start Game" button enables

5. **Click "Start Game"**
   - Both players begin playing
   - Everyone uses their custom keybinds

---

## For Player 2 (Guest)

1. **Open Link from Host**
   - Automatically joins the room
   - See keybind configuration screen

2. **Configure Your Keys (Optional)**
   - Default: **↑** to move up, **↓** to move down
   - To change: Click on a keybind field
   - Field turns yellow and says "press a key"
   - Press any key on your keyboard
   - Key is instantly saved
   - Click "Reset" to go back to defaults

3. **Wait for Host**
   - Screen says "Waiting for Host to Start Game"
   - Pulsing indicator shows you're connected
   - Can change keys anytime before game starts

4. **Game Starts**
   - Host clicks "Start Game"
   - Game begins with your custom keybinds

## Keybind Tips

✓ **Popular Keys to Bind**
- Letters: W, A, S, D, Q, E, R, T, F, G, H, J, K, L

- **Setup 1 (WASD style)**
  - Up: Q, E
  - Down: A, Z

- **Setup 2 (Arrows + Extra)**
  - Up: ArrowUp, W
  - Down: ArrowDown, S

- **Setup 3 (Mouse style)**
  - Up: W
  - Down: S

✓ **Test Your Keys**
- Before game starts, click on fields to verify
- Make sure keys are comfortable
- Try moving your paddle during game

## Common Questions

**Q: Can I change keys during the game?**
A: No, keybinds are locked once the game starts. Change them before clicking "Start Game".

**Q: What if we both pick the same key?**
A: It's allowed, but you might get confused! Each player uses their own keys independently.

**Q: Can I use modifier keys like Shift or Ctrl?**
A: Yes! Any physical key works. But be careful - Ctrl+Z might undo browser actions.

**Q: Are my keybinds saved between games?**
A: No, they're reset each game. You customize fresh every time you host/join.

**Q: What if I forget to set my keybinds?**
A: No problem! Defaults are used automatically:
- Player 1: W (up), S (down)
- Player 2: ↑ (up), ↓ (down)

**Q: Can I bind the Escape key?**
A: No, Escape is reserved for closing the game.

## Troubleshooting

**Issue: Field isn't responding to clicks**
- Make sure you're not in a game
- Click directly on the text field, not around it

**Issue: Key pressed but didn't register**
- Try clicking again to re-activate listening mode
- Some keys may be blocked by your system

**Issue: Can't see keybind fields**
- Refresh the page (F5)
- Check browser zoom level (should be 100%)

**Issue: Keybinds reset during game**
- This is normal, they lock when game starts
- Stop game, configure again, then start new game
