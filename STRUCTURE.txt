================================================================================
                               HOW TO COMPILE
================================================================================

From project root directory:

  $ javac src/game/PingPongGame.java

This automatically compiles all dependencies and outputs to build/classes/


================================================================================
                                HOW TO RUN
================================================================================

Option 1 - From source:
  $ java -cp src game.PingPongGame

Option 2 - From JAR:
  $ java -jar build/PongGame.jar

Option 3 - From IDE:
  Press F5 or click "Run" button


================================================================================
                             DIRECTORY PHILOSOPHY
================================================================================

This project uses a MODULAR structure:

  ✓ Each folder handles ONE responsibility
  ✓ Easy to find related code
  ✓ Easy to add new features
  ✓ Professional Java standard layout
  ✓ Scalable for larger projects

Example: Want to add a new projectile type?
  1. Create src/entities/NewProjectile.java
  2. Update src/physics/CollisionDetector.java
  3. Add render logic to src/game/PingPongGame.java
  4. Add constants to src/utils/GameConstants.java


================================================================================
                              KEY FEATURES
================================================================================

Game Modes:
  • Single Player vs AI
  • Local 2-Player
  • Online Multiplayer (NO PORT FORWARDING!)

AI System:
  • Learning AI that adapts to player skill
  • Tracks player behavior patterns
  • 4 difficulty levels (Normal, Hard, Impossible, Learning)

Online Multiplayer (No Port Forwarding!):
  • ngrok relay (easiest setup)
  • Tailscale VPN (most secure)
  • Direct IP (traditional port forwarding)
  • Automatic fallback between methods

Power-ups & Effects:
  • Danger zones
  • Gravity effects
  • Paddle modifiers
  • Special effects (Mirror, Teleport, Fireball, etc.)
